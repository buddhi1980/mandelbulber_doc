\section{Iteration loop}\label{iteration-loop}

In section \ref{mandelbrot-set} it was mentioned that fractals are calculated
by repeating a formula (\emph{iterating}) in an iteration loop. 
The integer \emph{i} is used to represent the \emph{iteration count} number.

The iteration count starts with \emph{i} = 0, then at the end of each iteration, the
count number is increased by 1, and the next iteration of the formula commences 
(e.g., iteration count  0, 1, 2, 3, ...). The iterating continues until \emph{termination conditions} are met, 
which is either when the iteration count \emph{i} =  \emph{maxiter} or when the \emph{bailout} condition is achieved. 

This section explains the calculations within the iteration loop.

A fractal formula is built from mathematical equations. 
These equations can be modifications of the Mandelbrot Set equation (e.g., Mandelbulb) and also other mathematical equations.

The equations are made from mathematical operators ($+, -, *, /$) 
and can include mathematical functions (e.g., sin, cos, tan, exp, log, sqrt, pow, abs) 
and also mathematical conditions (e.g., if x > y then ``compute following equation(s),'' if i > 4 then ``compute following equation(s)'').

The equations are applied to vector z or any parts of z (i.e., the z.x, z.y and z.z components)

Examples:

{\tt\emph{z.x} = fabs(\emph{z.x});} is using the function fabs() (which is floating-point version of abs()), where \emph{z.x} is assigned the absolute value of \emph{z.x}.

{\tt if (\emph{z.x} - \emph{z.y} < 0.0) swap(\emph{z.x}, \emph{z.y});} is using the conditional function if() to determine if the values of z.x and z.y should be swapped.

{\tt \emph{z} *= 3.0} is using the operator * to multiply all components of vector z by 3.0.

A set of equations that have a specific function within the formula are called \emph{transforms}, e.g., rotation, scale.

Generally a formula is constructed from one or more transforms, which are constructed from equations.

With each iteration of the formula, the point being iterated is \emph{mapped} (moved) to new coordinates as a result of the mathematical equations.

\subsection{Hybrid fractals}\index{fractal!hybrid}\label{hybrid-fractals}

\emph{Hybrid fractals} are constructed by using more than one formula in the iteration loop.
This way new variations of fractal shapes can be achieved. There are many different fractal formulas and transforms available in the Mandelbulber program, which allows the user to create a vast variety of hybrid shapes.

The key concept is that the vector \emph{z} is passed sequentially from one formula to the next. Each formula's \emph{FormulaCode()} mutates \emph{z} in-place, so the output \emph{z} of formula N becomes the input \emph{z} of formula N+1. This means each formula transforms the result of the previous one, creating complex combined shapes.

\subsubsection{Creating a hybrid fractal}\label{hybrid-fractals-creating}

Hybrids are created with the \emph{Objects tree} (chapter \ref{objects-tree}). The legacy
``Fractals'' tab with nine formula slots and the \emph{Enable hybrid fractals} checkbox no
longer exist; scenes saved in the old format are converted automatically when loaded.

To build a hybrid:
\begin{itemize}
	\item Press \emph{Add group} in the Objects tree panel and choose \emph{Hybrid fractal}
	in the group type dialog (figure \ref{iteration_loop_hybrid_group_dialog}).
	\item While the hybrid group is selected, press \emph{Add fractal} once for every formula
	of the sequence (or drag existing fractals into the group). A hybrid group accepts only
	fractal children; the order of the children in the tree is the order of the formulas in
	the iteration sequence.
\end{itemize}

\simpleImageWithCaptionThirdWidth{img/manual/media/objects_tree_group_dialog.png}
{The group type dialog, used to create a hybrid group}
{iteration_loop_hybrid_group_dialog}{H}

A fractal child of a hybrid group shows, in the editor below the tree, an additional frame
with the per-formula sequence controls (figure \ref{iteration_loop_hybrid_children}). The
formula's own parameters are edited on the same page, exactly as for a standalone fractal.
Settings shared by the whole sequence (\emph{Max Iterations}, Julia mode, constant factor)
are edited on the hybrid group node itself, in its calculation parameters (section
\ref{objects-tree-calc-params}). There is no upper limit on the number of formulas in the
group.

\simpleImageWithCaptionThirdWidth{img/manual/media/objects_tree_hybrid_children.png}
{Per-formula sequence controls of a fractal child of a hybrid group}
{iteration_loop_hybrid_children}{H}

In general hybrid fractals are calculated in a similar way to single formula fractals.
The calculation consists of the iteration loop, \emph{maxiter} and \emph{bailout} condition. The
difference is that inside the iteration loop a \emph{sequence} of several different fractal formulas (or transforms) is applied one after another, as shown on figure \ref{iteration_loop_hybrid}.

\simpleImageWithCaption75Width{img/manual/media/iteration_loop_hybrid.png}
{Complex Iteration loop with hybrid fractal}
{iteration_loop_hybrid}{H}

The sequence of formula execution is determined by the following parameters available on each fractal child of the hybrid group:
\begin{itemize}
	\item \emph{Formula} -- which fractal formula (or transform) this child contributes to the sequence
	\item \emph{Iterations} -- how many consecutive iterations this formula runs before advancing to the next child (default: 1)
	\item \emph{Start at iteration} -- the earliest global iteration number when this formula becomes active (default: 0)
	\item \emph{Stop at iteration} -- the latest global iteration number when this formula is active (default: 250)
	\item \emph{Weight} -- how strongly the result of this formula influences the orbit (default: 1.0, see section \ref{hybrid-formula-weight})
	\item \emph{Check for bailout condition} -- whether the iterations performed by this formula test the escape (bailout) condition (default: enabled; all these controls are described in detail in section \ref{objects-tree-editor})
\end{itemize}

Before rendering starts, the program builds a table which maps every global iteration number
to one formula of the group. The table covers the whole possible range of the iteration loop:
five times the \emph{Max Iterations} of the hybrid group (with the default value of 250 this is
1250 entries). During rendering, the iteration loop simply looks up which formula to apply for
each iteration index.
\footnote{For compatibility with scenes made before the Objects tree existed: if a hybrid has
	fewer than nine formulas, an orbit which passes the end of all formula ranges is terminated
	(the point is treated as belonging to the fractal body), emulating the empty slots of the
	old nine-slot hybrid mode.}

\subsubsection{Range of iterations for a formula}

The sequences can become more complicated by specifying the range of iterations when a formula will be calculated in the loop.

In the sequence controls of every fractal child the parameters \emph{Start at iteration} and \emph{Stop at iteration} are used to define this range.

When building the iteration table, the program walks through the children of the hybrid group in their tree order, checking the iteration range of each formula. If the current global iteration number is within the range of the next formula, this formula is assigned to the iteration and the global iteration count increases by 1. If the formula is outside its iteration range, it is skipped \emph{without consuming an iteration}: the next formula in the walk (wrapping back to the beginning of the group when the end is reached) performs the calculation for the current iteration number instead. If at some iteration none of the formulas is inside its range, the orbit is terminated there.

The example in figure \ref{iteration_loop_hybrid_sequence_4} continues the case from section \ref{two-iterations-per-slot}: the first two formulas have \emph{Iterations} set to 2, the third one stays at 1. In addition, the second formula (\emph{Menger Sponge}) has its iteration range set to \emph{from 4 to 250}.


\simpleImageWithCaptionFullWidth{img/manual/media/iteration_loop_hybrid_sequence_4.png}
{Hybrid sequence - Range of iteration set to 4-250 on the second formula (Iterations 2 on the first two formulas)}
{iteration_loop_hybrid_sequence_4}{H}

The walk reaches the \emph{Menger Sponge} for the first time at iteration 2, but this is still outside its range (\emph{Start at iteration} was set to 4), so the formula is skipped and the \emph{Box Fold Bulb Pow 2} performs this iteration instead. The \emph{Menger Sponge} is used for the first time at iteration 5; from then on the sequence repeats normally: Menger Sponge (2 iterations), Box Fold Bulb Pow 2, Mandelbulb -- Power~2 (2 iterations).

The shape of the resulting fractal is shown in figure \ref{hybrid_sequence_example_4}.

The order of the formulas inside the sequence is the order of the fractal children in the Objects tree. It can be easily changed with drag and drop: move a child to a different position among the siblings (figure \ref{iteration_loop_hybrid_reorder}, section \ref{objects-tree-drag-drop}).

There are also a few formulas and transforms which have a very strong influence on the final shape, and these are often run for just 1 or 2 iterations during the iterating of the fractal.

\subsubsection{Formula weight (blending)}\label{hybrid-formula-weight}

Each fractal child has a \emph{Weight} parameter (range 0.0 to 1.0, default 1.0) that controls how much the formula's output contributes to the result.
When the weight is less than 1.0, the position of \emph{z} after the formula is smoothly interpolated between the state \emph{before} the formula and the state \emph{after} it; the accumulated DE and color values are blended in the same way.
This allows for gradual transitions between formulas and can produce unique visual effects.
A weight of 0.0 disables the calculation of the formula entirely: the orbit passes through the corresponding iterations almost unchanged, but the iterations are still consumed.
Blending is only applied inside hybrid groups; outside of a group the weight has no effect.

\subsubsection{Legacy ``repeat from'' setting}

The \texttt{repeat\_from} parameter (range 1 to 9, default 1) is an abandoned relic of the old
nine-slot hybrid mode, where it selected the slot to which the sequence wrapped back at the
end (setting it to 2 produced a pattern like: A, B, C, B, C, B, C, ...). It has been replaced
by the per-formula \emph{Start at iteration} and \emph{Stop at iteration} ranges, which allow
expressing the same and much more complex patterns. The current interface offers no control
for this parameter; it is still read from old scene files only to reproduce the sequences of
legacy hybrids as accurately as possible.
